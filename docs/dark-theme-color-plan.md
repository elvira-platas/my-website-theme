# План цветовой системы тёмной темы

Этот документ хранит решения по будущей тёмной теме Kilka. Он должен
обновляться после каждого визуального прохода, чтобы утверждённые цвета и
отклонённые варианты не приходилось восстанавливать по памяти.

## Статус

- Тёмная тема пока не реализована.
- Чистый чёрный не рассматривается как исходная поверхность обычного сайта.
- Ниже записана первая рабочая палитра; она ещё не утверждена визуально.
- Светлая тема остаётся самостоятельной основной схемой, а не временным
  состоянием до появления тёмной.
- Предварительное управление: `Авто · Светлое · Тёмное` внутри раскрывающегося
  Primary Menu. `Авто` следует системной настройке, ручной выбор сохраняется в
  браузере, схема применяется до первой отрисовки страницы без светлой вспышки.

## Замысел

Тёмная тема должна восприниматься как тот же сайт при другом освещении:

- Main Blog — тёмная читальная комната с отдельным листом-карточкой;
- Second Blog — единая размеченная плоскость без карточек;
- Exhibition — более глубокая галерейная стена, где основным световым объектом
  становится работа;
- элементы управления сохраняют объём, но не превращаются в светящиеся кнопки;
- фотографии продолжают находиться на расстоянии от стены, а не приклеиваются к
  ней и не получают декоративное неоновое свечение.

## Правила по разделам

### Main Blog

- Поле страницы: `#18191D`.
- Карточка: `#23252B`.
- Карточка отделяется разницей поверхностей, а не яркой рамкой или усиленной
  тенью.
- Sticky-записи потребуют отдельного спокойного варианта поверхности; значение
  ещё не выбрано.

### Second Blog

- Весь поток и single-view используют одну плоскость `#1C1D22`.
- Карточный фон не возвращается.
- Основные уголки: черновой `rgba(171, 139, 255, 0.68)`.
- Второй контур: черновой `rgba(171, 139, 255, 0.34)`.
- Третий контур: черновой `rgba(171, 139, 255, 0.16)`.
- Нужно отдельно проверить, не превращаются ли уголки в неон на тёмной стене.

### Exhibition

- Базовая тёмная стена: `#151619`.
- Информационная панель: `#24262C`.
- Затемнение под открытой панелью должно стать плотнее текущего светлого
  `rgba(36, 36, 36, 0.18)`; точное значение пока не выбрано.
- Явно заданный куратором `Wall tone` нельзя автоматически инвертировать.
  До реализации нужно решить, сохраняем ли его в обеих схемах или добавляем
  отдельный optional dark wall tone.

## Кнопки и стрелки

Не все стрелки должны иметь одинаковый объём:

- Continue Reading / More остаётся плоской текстовой или фиолетовой ссылкой;
- круглые post navigation и Back to top получают тёмную поверхность, границу и
  тень;
- кнопки Menu и `i` в Exhibition должны занимать минимум изображения, поэтому
  возможность оставить их прозрачными проверяется отдельно.

Первая модель тени обычной круглой кнопки:

```css
box-shadow:
  0 1px 0 rgba(255, 255, 255, 0.05),
  0 6px 18px rgba(0, 0, 0, 0.45);
```

Светлый верхний слой обозначает край поверхности; это не декоративное свечение.
SVG-стрелки в `background-image` должны получать тёмную схему структурно, а не
через CSS-фильтр.

## Парение фотографий

Существующая двухслойная тень используется и в Exhibition, и у обложек Second
Blog. На тёмной стене предлагается сохранить общий язык, добавив очень тонкое
краевое освещение:

```css
box-shadow:
  0 0 0 1px rgba(255, 255, 255, 0.08),
  0 8px 16px rgba(0, 0, 0, 0.52),
  0 36px 60px -12px rgba(0, 0, 0, 0.65);
```

Первый слой нужен только для тёмных краёв самой фотографии. Он не должен
восприниматься как рамка, белый ореол или подсветка. Для mobile понадобятся
меньшие смещение и размах; значения ещё не выбраны.

## Открытые решения

- Насколько заметной должна быть разница между полем и карточкой Main Blog.
- Не слишком ли холодны `#18191D` и `#23252B` рядом с конкретными фотографиями.
- Финальная яркость трёх контуров Second Blog.
- Поведение пользовательского Exhibition Wall tone.
- Прозрачные или поднятые Menu / `i` внутри Exhibition.
- Точные тени кнопок и фотографий на desktop и mobile.
- Цвета полей поиска, форм, выделения текста, focus-ring и состояний ошибок.
- Нужно ли дать пользователю возврат из ручного режима в `Авто` одним действием.
